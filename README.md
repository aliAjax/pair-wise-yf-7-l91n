# 活字排版工坊

一个纯前端本地应用，用来维护字模库、在网格版面中落字、检查字模数量是否超用、保存草稿并导出 PNG 预览图。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。

## 多纸样分版

一张草稿同时排三张纸样：**明信片（16×10）、书签（7×18）、方形小笺（12×12）**。

- 切换纸样只切换当前视图；每个纸样的**落字位置、网格间距、横/竖排方向**分别保存，互不影响。
- 书签格数少，从其它纸样带过来（或旧数据迁移进来）的越界落字**不会被删除**，而是保留在原版数据中，并在版面上方列出每条冲突（行、列、字模）。导出图只画界内格。
- 顶部纸样小条可直接切换，并显示各版落字数与是否已启用。

## 保存与载入

- 保存前原地校验，任一不满足则**整张草稿不动**（不新增、不覆盖），并在侧栏直接说明：
  - 作品名不能为空；
  - 每个「已用纸样」都必须有落字（漏排版会列出纸样名）。
- 清空某一版的落字不会让该纸样退出「已用」，因此漏排版仍会被拦住。
- 导出按**当前纸样**出图，文件名含作品名与纸样名。

## 页面接续

在版面上方的接续框粘贴一段文字，会按当前纸样的阅读顺序（横排先行后列、竖排从右列到左列、列内自上而下）把字依次落到空格。当前页放满即停，未放下的字原样留在输入框；字模库存不足的字会被跳过并列出。

## 脚本分工

| 文件 | 职责 |
| --- | --- |
| `papers.js` | 纸样校验：三种纸样尺寸/编号、网格间距与方向取值、越界与冲突判定，启动时自检 |
| `migrations.js` | 数据迁移：旧版单份 `settings + placements` 结构补齐为按纸样分版，旧草稿载入时自动补齐三张纸样 |
| `continuation.js` | 页面接续：阅读顺序、字模匹配、落字与溢出/缺字计算（纯数据） |
| `app.js` | 界面渲染、交互、保存/载入/导出与 localStorage |

数据结构（localStorage 键 `zfl16-movable-type-workshop`，`version: 2`）：

```jsonc
{
  "version": 2,
  "currentPaperSize": "bookmark",
  "workTitle": "晚风小笺",
  "inventory": [ /* 字模 */ ],
  "blocks": {
    "postcard": { "settings": { "flowMode": "horizontal", "gridGap": 8 }, "placements": [ /* {row,col,typeId} */ ], "used": true },
    "bookmark": { "settings": { "flowMode": "vertical", "gridGap": 10 }, "placements": [], "used": true },
    "square":   { "settings": { "flowMode": "horizontal", "gridGap": 8 }, "placements": [], "used": false }
  },
  "drafts": [ /* 每篇草稿各存一份 blocks */ ]
}
```
